# 故障转移与熔断

请求失败后，AiDog 根据失败类型决定是否尝试其他模型或平台。模型相关错误可排除当前平台与模型组合；服务类错误可排除整个平台。请求不会转到其他分组。

连接失败、限流、鉴权错误等会按分组调度模式更新平台健康状态或冷却状态。健康感知模式使用逐次加长的熔断时间；其他模式按失败阈值熔断。成功请求会清除连续熔断失败计数。

重试次数有限。耗尽后，请求返回最后一次上游错误或路由失败结果。查看代理日志中的每次尝试与失败阶段，可判断问题来自模型、凭证、上游服务还是本机网络。
