# 故障转移与熔断

故障转移会在当前候选失败后尝试同组下一个兼容候选，不跨分组，也不强行使用不兼容模型或协议。

失败分类（2026-09-15 起）：网络错误（连不上/超时/断流）、上游 5xx、200 空响应**不影响调度**——下一轮仍按原优先级选择该平台；上游主动限流（429 非配额类）计入熔断，临时踢出一段时间后自动半开探测恢复；余额不足（402）与鉴权失败（401）触发**固定 5 分钟内存冷却**，不改变平台启用状态，到点自动回调度；配额耗尽（429 配额类）按上游给出的重置时间冷却。排障时先看日志失败阶段，再检查候选顺序、平台状态、模型与端点协议。高峰禁用是独立闸门。
