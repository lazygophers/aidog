# 数据与隐私

AiDog 将配置和数据库保存在本机。代理请求仍会发送到你选择的上游服务；上游会收到处理请求所需的内容。请按上游服务的隐私条款选择数据和平台。

代理日志可以分别控制用户侧与上游侧原始请求内容的记录。关闭某侧原始内容记录后，该侧请求头、正文和响应正文不会保留；请求状态、模型、用量等元数据仍会记录。Authorization 等敏感请求头在记录前会脱敏。

原始内容保留期到期后，AiDog 清空相应原始字段。整行保留期到期后，才删除整条代理日志。测试、余额查询和拉取模型等请求使用独立请求日志。

备份或导出的文件可能包含凭证。限制文件访问，不要把真实配置或备份提交到公开代码仓库。
