# 接入 Codex

1. 在 AiDog 中添加并测试上游平台。
2. 创建分组并加入平台。
3. 从分组操作中复制 Codex 启动命令。
4. 运行命令并发送一次请求。

AiDog 会同步 Codex provider 配置。分组 key 是 Codex 访问 AiDog 的凭据，不是上游 API Key。若手动编辑 `~/.codex/config.toml`，需保持 provider 的 `base_url`、`wire_api` 与环境变量名和分组设置一致。

详细字段见[Codex 推荐配置](/features/recommended-codex)。完成后按[验证首个请求](/getting-started/first-request)检查路由日志。
