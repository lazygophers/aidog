# 接入 pi

先安装并运行 pi。然后在 AiDog 中创建分组、加入平台，并在分组配置中选择 pi 使用的协议。

AiDog 会为该分组生成 pi provider，并写入 pi 的 `models.json`。分组列表中的“复制启动命令”可生成选择对应 provider 的命令。运行前检查命令中的分组名与协议。

AiDog 管理 `aidog-` 前缀的 provider 条目；其他 provider 配置会保留。pi 不提供 Claude Code 式 Hooks 或 StatusLine 配置。完成后按[验证首个请求](/getting-started/first-request)检查日志。
