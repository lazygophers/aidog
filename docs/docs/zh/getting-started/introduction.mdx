# 产品介绍

AiDog 是本机运行的 AI API 网关。它在一个桌面应用中管理上游平台、分组、模型映射、代理请求与用量记录。

## 请求如何流动

`客户端 → 本机代理 → 分组鉴权 → 分组候选平台 → 协议适配 → 上游服务`

客户端用分组凭据连接代理。AiDog 根据分组配置选择平台和模型，再把请求转发给上游。上游仍会收到处理请求所需的数据。

## 适用范围

AiDog 面向个人本机使用，也提供可选的 headless 内核。它不是云端账号服务；默认代理只监听本机地址。管理接口应保持本机访问，不要暴露到公网。
