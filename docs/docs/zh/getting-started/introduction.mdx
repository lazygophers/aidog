# 产品介绍

aidog 是运行在本机的桌面端 AI API 网关。它把多个上游平台统一成一个代理入口，并负责协议转换、模型映射、路由、故障转移、计量和日志记录。

## 请求如何流动

`客户端 → aidog 本地代理 → 分组匹配 → 候选平台 → 协议适配 → 上游模型`

客户端只需使用本地代理地址和分组名。平台 API Key 保存在 aidog 中，不必分发给每个工具。所有配置与 SQLite 数据默认保存在本机，但上游仍会收到被转发的请求内容。
