# 首次配置

## 1. 添加上游平台

打开“AI 平台”，添加一个平台。选内置预设时检查协议与 Base URL，再填写该平台的 API Key。自定义平台也要选择与上游接口相符的协议。

Base URL 应包含上游需要的版本前缀，例如 `/v1`。不要把 `/chat/completions` 拼进 Base URL；请求路径由 AiDog 根据协议构造。

## 2. 创建分组

在“AI 平台”页创建分组，并把刚添加的平台加入分组。分组凭据用于客户端访问 AiDog；它不是上游 API Key。仅将兼容的候选平台放在同一分组。

## 3. 检查本机代理

默认代理地址是 `http://127.0.0.1:9890`。在终端运行：

```bash
curl http://127.0.0.1:9890/
```

成功时返回 `{"service":"aidog","ok":true}`。然后按[客户端接入指南](/getting-started/connect-claude-code)配置客户端。
