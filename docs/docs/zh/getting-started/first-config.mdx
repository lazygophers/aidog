# 首次配置

## 添加平台

进入“AI 平台”，选择预设协议并填写名称、Base URL 和 API Key。Base URL 应包含版本前缀，例如 `/v1`。

## 创建分组

在平台页内创建分组并关联平台。分组名也是代理鉴权使用的 Bearer token。
进入“AI 平台”，选择预设协议并填写名称、Base URL 和 API Key。Base URL 应包含版本前缀，例如 `/v1`；不要再拼接 `/chat/completions`。

## 创建分组

进入“分组路由”，创建分组并关联平台。分组名也是代理鉴权使用的 Bearer token。先用单平台分组验证链路，再添加兼容候选实现故障转移。

## 确认代理

```bash
curl http://127.0.0.1:9890/
curl http://127.0.0.1:9890/
```

返回 `{"service":"aidog","ok":true}` 后即可接入客户端。
