# 安装指南

从 [GitHub Releases](https://github.com/lazygophers/aidog/releases/latest) 下载最新版本，并按发布页提供的文件安装。安装包、系统版本和处理器架构以该版本发布页为准。

macOS 或 Windows 若出现系统安全提示，请先确认安装包来自 AiDog 官方 Releases，再按系统提示允许打开或安装。Linux 请查看发布页说明及 [Tauri 系统依赖](https://v2.tauri.app/start/prerequisites/)；不要照搬其他发行版的安装命令。

启动后，桌面应用会启动本机服务。代理默认地址为 `http://127.0.0.1:9890`。默认只接受本机连接。

继续[首次配置](/zh/getting-started/first-config)。
