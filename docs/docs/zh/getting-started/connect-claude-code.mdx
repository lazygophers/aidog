# 接入 Claude Code

1. 在 AiDog 中添加并测试上游平台。
2. 在“AI 平台”页创建分组，并把平台加入该分组。
3. 从分组操作中复制 Claude Code 启动命令。
4. 在终端运行该命令，并发送一次请求。

AiDog 会为分组准备 Claude Code 配置。分组凭据用于客户端连接本机代理，不是上游 API Key。启动命令可能包含权限或模式参数；运行前先阅读命令内容，并按自己的安全要求调整。

若手动配置环境变量，使用 `ANTHROPIC_BASE_URL` 指向 AiDog 的本机 `/proxy` 地址，并使用 `ANTHROPIC_AUTH_TOKEN` 提供分组凭据。完成后按[验证首个请求](/zh/getting-started/first-request)检查日志。
