# 接入 Claude Code

进入 aidog 的“AI 平台”或分组列表，找到要使用的分组，点击“复制启动命令”并选择“Claude Code 启动命令”。

生成器在 `src/domains/groups/commands.ts`。当前命令形态是：

```bash
claude --brief --dangerously-skip-permissions --settings ~/.aidog/settings.<group>.json
```

aidog 会先把该分组的 Claude Code 配置写入对应 `settings.<group>.json`，命令本身只负责指向这份配置文件。不要手写 `export` 作为主流程。
