# 验证首个请求

```bash
curl http://127.0.0.1:9876/proxy/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <group_name>' \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"只回复 ok"}]}'
```

收到响应后，在日志页确认状态码、分组、平台、请求模型、实际模型、Token 和费用。失败时依次核对分组名、候选平台状态、模型映射和代理服务状态。
