# 验证首个请求

先在 AiDog 的分组详情中复制分组凭据，并确认该分组至少有一个启用的平台。把 `<group_key>` 换成分组凭据，把 `gpt-4o` 换成上游支持的模型名：

```bash
curl http://127.0.0.1:9890/proxy/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <group_key>' \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"只回复 ok"}]}'
```

请求成功后，在“代理日志”查看状态码、分组、平台、请求模型、实际模型和用量。费用是根据记录到的用量和模型价格估算的，不等同上游账单。

请求失败时，先确认代理已启动、分组凭据正确、平台已启用，并且模型映射与上游端点匹配。日志详情可显示失败阶段和上游响应。
