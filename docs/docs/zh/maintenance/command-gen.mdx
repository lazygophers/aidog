# 命令字典生成

`docs/docs/zh/api/commands.generated.mdx` 由根目录脚本生成。脚本读取 Tauri 命令注册表、Rust 命令签名和 TypeScript 调用封装。

修改命令或调用封装后，在仓库根目录运行：

```bash
node scripts/gen-command-docs.mjs
node scripts/gen-command-docs.mjs --check
```

第一条命令更新生成文件；第二条检查文件是否与当前源码一致。不要直接手改 `commands.generated.mdx`，也不要把命令字典当作稳定的远程 API 契约。
