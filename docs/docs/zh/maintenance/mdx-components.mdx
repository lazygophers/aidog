# MDX 组件

文档页可使用 Rspress 支持的 Markdown 与 MDX 语法。提示框、Tabs 和代码块优先用内置能力，避免为单页新增组件。

功能页面的 `ProductDemo` 使用固定、脱敏的 fixture 展示示意状态。它不读取桌面应用、用户数据库、Tauri IPC 或本机 API。它只用于说明内容结构，不作为当前应用界面或功能行为的证据。

```mdx
import { ProductDemo } from '../../../theme/components/ProductDemo';

<ProductDemo module="platforms" state="normal" />
```
