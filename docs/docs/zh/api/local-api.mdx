# Local API

Local API 绑定本机代理。业务端点以 `/api/` 开头且只接受 POST；健康检查和静态模型探测为例外。

| 方法与路径 | 鉴权 | 用途 |
| --- | --- | --- |
| `POST /api/group-info` | `Bearer <group_name>` | 查询分组信息 |
| `POST /api/notify` | 以源码门禁为准 | 发送本机通知 |
| `GET /`、`GET /proxy` | 无 | 健康检查 |
| `GET /models`、`GET /v1/models` | 无 | 返回静态默认模型列表 |

```bash
curl -X POST http://127.0.0.1:9890/api/group-info \
  -H 'Authorization: Bearer <group_name>'
```

这些端点仅供 localhost 使用，禁止通过反向代理暴露到公网。
