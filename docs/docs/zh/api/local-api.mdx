# Local API

Local API 绑定本机代理。业务端点以 `/api/` 开头且只接受 POST；健康检查和静态模型探测为例外。Router 定义在 `src-tauri/crates/aidog_core/src/gateway/proxy/mod.rs`。

| 方法与路径 | 鉴权 | 用途 |
| --- | --- | --- |
| `POST /api/group-info` | `Bearer <group_key>` | statusline 查询单平台分组的本地预估信息；多平台或无平台返回 `applicable:false` |
| `POST /api/notify` | `Bearer <group_key>` | hook 脚本触发本机通知；body 支持 `event`、`type`、`content`、`vars` |
| `GET /`、`GET /proxy` | 无 | 健康检查，返回身份 JSON，不进组路由、不落代理日志 |
| `GET /models`、`GET /v1/models` | 无 | 返回静态默认模型列表，分流发生在分组解析前 |

```bash
curl -X POST http://127.0.0.1:9890/api/group-info \
  -H 'Authorization: Bearer <group_key>'
```

不要把 Local API 反向代理到公网。它的鉴权对象是 aidog 分组 key，不是上游 API Key。
Local API 绑定本机代理。业务端点以 `/api/` 开头且只接受 POST；健康检查和静态模型探测为例外。

| 方法与路径 | 鉴权 | 用途 |
| --- | --- | --- |
| `POST /api/group-info` | `Bearer <group_name>` | 查询分组信息 |
| `POST /api/notify` | 以源码门禁为准 | 发送本机通知 |
| `GET /`、`GET /proxy` | 无 | 健康检查 |
| `GET /models`、`GET /v1/models` | 无 | 返回静态默认模型列表 |

```bash
curl -X POST http://127.0.0.1:9890/api/group-info \
  -H 'Authorization: Bearer <group_name>'
```

这些端点仅供 localhost 使用，禁止通过反向代理暴露到公网。
