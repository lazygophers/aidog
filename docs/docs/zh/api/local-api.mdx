# 本机 API

AiDog 在代理端口提供部分 HTTP 管理接口。业务接口只接受指定 HTTP 方法；管理接口只允许本机连接，并可在“系统设置 → API”关闭或设置凭据。不要通过反向代理或端口转发公开这些接口。

| 路径 | 方法 | 鉴权与用途 |
| --- | --- | --- |
| `/api/rpc/<命令>` | POST | 本机管理调用；可配置 Bearer 凭据。 |
| `/api/events` | GET | 本机 Server-Sent Events 事件流；可配置 Bearer 凭据。 |
| `/api/group-info` | POST | 使用 `Bearer <group_key>` 查询分组信息。 |
| `/api/notify` | POST | 使用 `Bearer <group_key>` 发送本机通知。 |
| `/mcp` | POST | HTTP MCP；使用分组凭据，且只允许本机连接。 |
| `/`、`/proxy` | GET | 健康检查，不要求鉴权。 |
| `/models`、`/v1/models` | GET | 模型发现端点。 |

`group_key` 是 AiDog 分组凭据，不是上游 API Key。API 总开关关闭时，管理接口不可用。具体命令和请求字段请以当前版本的生成字典与源码为准。

```bash
curl -X POST http://127.0.0.1:9890/api/group-info \
  -H 'Authorization: Bearer <group_key>'
```
