# 调用契约与错误

桌面前端通过 Tauri 调用 Rust 命令。命令必须注册，调用名称、参数名称和序列化类型必须匹配。修改任一侧时，检查注册表、Rust 实现和 TypeScript wrapper，并重新生成[命令字典](/zh/api/commands.generated)。

本机 HTTP API 是另一组接口，遵守各自的路径、HTTP 方法和鉴权要求。Tauri Command 不是远程 HTTP API；没有记录在接口说明中的命令不应视为公共扩展接口。
