# API 概览

AiDog 提供供本机工具使用的 HTTP API，也使用 Tauri IPC 连接桌面前端与 Rust 后端。

- [本机 HTTP API](/zh/api/local-api)
- [Tauri Command 使用方式](/zh/api/tauri-commands)
- [生成的命令字典](/zh/api/commands.generated)
- [调用契约与错误](/zh/api/contracts)

HTTP 管理接口仅限本机访问。Tauri Command 只供应用内部调用，不是远程服务接口。
