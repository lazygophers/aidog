# 系统设置

系统设置包含代理服务、Claude Code、Codex、pi、中间件、调度、通知、定价、托盘、导入导出和 MITM 等配置区。各区控制不同功能，修改前先确认作用范围。

## 出站网络代理

系统代理配置用于 AiDog 发出的 HTTP、HTTPS 或 SOCKS5 请求。平台可单独选择是否使用该代理；其他出站请求由“其它请求使用代理”控制。代理主机为空时请求直连，免代理名单优先使匹配主机直连。

本地代理监听地址与出站网络代理是不同设置：前者供客户端连接 AiDog，后者供 AiDog 连接上游。
