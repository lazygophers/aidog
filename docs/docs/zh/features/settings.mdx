## 当前实现

侧栏的 `settings` 入口挂载 `src/pages/AppSettings.tsx`，内含多个 tab。`src/App.tsx` 通过 `settingsTab` 传入当前分区。

按当前源码，设置页至少覆盖：`system`、`coding_tools`、`claude`、`codex`、`middleware`、`scheduling`、`notifications`、`pricing`、`tray`、`popover`、`importexport`、`mitm`。相关命令分散在 `src/services/api/` 和 `src-tauri/src/startup.rs`。

## 主要任务

此页面演示正常、空、错误和加载四种固定状态。演示数据已脱敏，不连接本机 aidog、Tauri IPC 或 Local API。

在桌面应用中使用左侧导航进入“系统设置”。保存会影响运行状态的设置前，先确认当前分组和平台范围；发生错误时结合[代理日志](/zh/features/logs)定位。
