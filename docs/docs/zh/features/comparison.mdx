# 同类工具对比

aidog 属于「本地 / 自建 AI API 网关」一类工具。本文把它与同类开源项目放在一张表里对照，只陈述功能有无与形态差异，不评优劣——选型取决于你的使用场景。

对比对象与数据来源：竞品功能均转述自各项目官方仓库的 README 与 LICENSE（2026-11-08 抓取，出处见文末），aidog 功能以本仓库代码与文档为准。各项目迭代都很快，功能以官方当前文档为准。

## 与 magpie 对比

[magpie](https://github.com/yetone/magpie)（MIT，2026-11-08 时约 3.1 万 stars）是与 aidog 定位最接近的项目：同为面向个人开发者的本地 AI API 网关，同样做「多平台聚合 → 统一路由 → 编程助手接入」。

**aidog**：本地 AI API 代理网关桌面应用（Rust + Tauri + React）。核心是多平台分组路由、多协议转发、模型链降级、计费统计、请求日志与逐请求检查器、Claude Code / Codex / pi 配置生成、Skills 与 MCP 管理、headless 内核（`--ui` 网页界面）；8 语言界面（含 RTL）、SQLCipher 整库加密。

**magpie**（Go + Wails）：「所有 Agent 的模型，一处搞定」。核心是 70+ 编程助手配置改写、四协议互转、订阅账号桥接成 provider、路由组调度、隐私脱敏、Bun 插件系统、菜单栏 / TUI / Web / CLI / Docker / Termux 多形态。

### 功能对照

| 功能维度 | aidog | magpie |
| --- | --- | --- |
| 平台 / provider 管理 | 多平台管理、批量操作、从平台拉取模型列表、订阅信息导入 | 30+ 预设 provider、厂商 API 直拉模型、订阅账号发现与登录、支持从 CC Switch 等工具导入 |
| wire 协议 | OpenAI Chat / Completions / Responses、Anthropic、Gemini 等多协议双向互转 | OpenAI Chat / Responses、Anthropic、Gemini 四协议互转（流式、工具调用、推理均支持） |
| 路由策略 | 5 类调度模式（failover / rotate / usage / pace / smart）叠加分组分档、coding plan 上浮、透传优先；模型链逐个自动降级 | 路由组 5 模式（smart / order / rotate / usage / pace），支持嵌套路由组与意图路由（小模型按消息内容选模型） |
| 额度感知 | 平台级余额探测、Coding Plan 配额、高峰倍率窗口；路由支持按剩余额度 / 最快重置排序 | 每 key / 账号额度跟踪、订阅 5 小时窗口每日预热 |
| 提示词缓存亲和 | 有（30 分钟粘性调度 + 缓存感知条件绑定，默认关） | 有（缓存值得保留时对话固定在同一账号） |
| 消费上限 | 中间件预算规则 | 每 key / 账号按天 / 月 / 累计美元上限，超限自动切换 fallback |
| 隐私脱敏（出站） | 有（默认关）：规则引擎（密钥 / 邮箱 / 银行卡 / 证件号）+ 本地 PII 模型后端接口，占位符双向还原，服务不可达时拦截请求 | 有（默认关）：规则 + 本地 PII 模型两级检测，占位符双向还原（含流式与工具参数），失败拦截 503 |
| 计费与统计 | token / 费用 / 余额 / Coding Plan 配额 / 会话级统计，多币种 | token / 缓存 / 推理 token 按官方价计费、每 key 额度、上下文占用分析、OTLP 导出 |
| 日志审计 | 请求日志 + 逐请求检查器 + MITM 抓包 + 3 级保留期 | 脱敏观测对照页；无逐请求检查器 |
| 客户端配置生成 | Claude Code / Codex / pi 全套（settings、statusline、hooks、按分组下发）+ 配置卸载恢复 + Profile 方案 + agent 版本更新 | 70+ agent 原子改写 + Profile 方案 + agent 版本更新 + WSL |
| Skills / MCP | Skills 扫描安装更新 + MCP 扫描导入绑定 + 内置 stdio MCP server | Library（指令 / MCP / 技能 / 子代理按各 agent 格式分发）+ MCP router |
| 插件系统 | 内置中间件规则引擎（改写 / 预算 / 敏感词 / 错误检测） | Bun 插件运行时（provider 插件 + 网关中间件插件 + 插件市场） |
| 联网搜索 / 生图 | web_search 聚合多家搜索 provider + web_fetch + 生图 MCP 工具 | 9 家搜索聚合为 MCP + 生图 / 生视频 MCP 工具 |
| 同步与共享 | 局域网绑定、分组 token、导入导出、本地备份计划、平台分享码 | 局域网共享（每客户端 key + 预算）、远程实例互连、WebDAV / S3 / GitHub 加密同步 |
| 部署形态 | 桌面应用 + headless 内核（`--ui` 网页界面） | 菜单栏 + 窗口 + TUI + Web + CLI + daemon + Docker + Android Termux |
| 通知系统 | webhook / SMTP / TTS / 弹窗 / 收件箱 + 规则 | 额度窗口重置提醒 |
| 界面语言 / 数据加密 | 8 语言含 RTL、SQLCipher 整库加密、自动更新 | 多语言界面、遥测（可关）、macOS 签名自动更新 |

### 尚未对齐的能力

- **订阅账号当 provider**：magpie 可把本机登录的 Claude / ChatGPT / Copilot / Gemini / Grok 订阅桥接成网关里的 provider 给任意助手用；aidog 目前只支持导入订阅信息，不做订阅桥接。这是两代产品间 aidog 最大的能力缺口。
- **插件运行时**：magpie 有 Bun 插件系统（provider 插件 + 网关中间件 JS 插件 + 插件市场）；aidog 用内置中间件规则引擎覆盖改写 / 预算 / 敏感词等高频场景，无 JS 插件运行时。
- **远程配置同步**：magpie 支持加密备份同步到 WebDAV / S3 / GitHub；aidog 的备份目前是本地产物，无远程同步。
- **agent 配置广度**：magpie 覆盖 70+ 助手；aidog 深耕 Claude Code / Codex / pi 三家（settings、statusline、hooks 全套），广度换深度是既有取舍。

## 同类网关横评

| 维度 | aidog | magpie | Claude Code Router | new-api | LiteLLM Proxy | CLIProxyAPI | GPT-Load |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 形态 | 桌面应用 + headless 内核 | 菜单栏 + TUI / Web / CLI / Docker / Termux | 桌面应用 + npm CLI + Docker | 自托管服务端（Docker） | Python SDK + 网关服务 | CLI 代理服务（Go） | 自托管服务端（Docker） |
| 面向对象 | 个人开发者 | 个人开发者 | 编程助手用户 | 团队 / 组织 | 应用与团队 | 开发者 | 团队 / 多凭证场景 |
| provider 聚合 | 50+ 预设平台 | 30+ 预设 + 订阅账号 + 本地模型 | 内置预设 + 自定义端点 | 渠道制（任意 OpenAI 兼容上游） | 100+ provider 统一 OpenAI 格式 | 订阅账号为主 | 渠道制（API key + 订阅 OAuth） |
| 协议能力 | 多协议双向互转 | 四协议互转（含流式与工具调用） | OpenAI / Anthropic / Gemini 多协议 | 四协议互转 + Realtime WebSocket + 图音接口 | 统一 OpenAI 格式调用 100+ provider | OpenAI / Gemini / Claude 兼容接口 | 原生协议透传（不互转） |
| 编程助手集成 | Claude Code / Codex / pi 全套（settings、statusline、hooks、按分组下发） | 70+ agent 原子改写 + Profile | 10+ agent 配置下发 + Profile | 无专门支持 | 无专门支持 | 任意可填 base URL 的客户端 | 任意可填 base URL 的客户端 |
| 路由策略 | 5 类调度模式 + 分组分档 + 模型链降级 | 5 模式路由组 + 嵌套 + 意图路由 | 重试、凭证池、key 轮换、顺序降级 | 渠道优先级 / 权重 / 重试 / 亲和 | 负载均衡 + fallback + 按复杂度自动路由 | 多账号轮换 | 多凭证调度（权重 / 重试 / 冷却 / 黑名单 / 会话亲和） |
| 出站隐私脱敏 | 有（默认关） | 有（默认关，规则 + 本地 PII 模型） | 无此声明 | 无此声明 | 无此声明 | 无此声明 | 无此声明 |
