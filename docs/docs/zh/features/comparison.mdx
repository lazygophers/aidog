# 选择 AiDog

AiDog 面向希望在个人电脑上管理上游 AI 平台，并让本地客户端经统一入口访问这些平台的用户。

## AiDog 提供

- 桌面应用和可选 headless 内核。
- 本机代理、分组凭据、平台候选和模型映射。
- 支持多种上游协议的请求转发与适配；具体支持范围取决于请求类型和端点。
- 请求日志、用量记录和费用估算。
- Claude Code、Codex 和 pi 配置管理。

## 使用前了解

- AiDog 默认在本机运行，不提供托管的云端网关。
- 代理请求会发送给所选上游，敏感内容需按上游政策处理。
- 费用是根据可用用量与价格信息估算的，不等同上游账单。
- 不同客户端和协议的能力不同；跨协议转换不保证覆盖每个功能。

若你需要集中部署给团队或远程用户访问，请先评估网络暴露、鉴权和数据管理要求。AiDog 的管理接口默认只允许本机访问。
