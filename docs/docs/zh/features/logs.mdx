# 代理日志与请求日志

代理日志记录经网关处理的请求，包括状态、分组、平台、模型、用量、费用估算、耗时和重试尝试。测试、余额查询、模型列表获取等记录在独立的请求日志中。

## 原始内容与保留期

设置可分别控制用户侧和上游侧原始请求信息。关闭一侧记录后，该侧请求头、正文和响应正文不会保留；代理日志的请求状态等元数据仍会记录。Authorization 等敏感请求头在写入前脱敏。

原始字段保留期到期后会清空原始内容，但保留代理日志行。整行保留期到期后才删除代理日志。查看请求详情时，按日志记录核对实际发送的上游地址、请求内容和返回错误。

费用是估算值，缺失上游用量时无法准确计算。请勿把日志导出或截图公开，其中可能含有业务内容。
