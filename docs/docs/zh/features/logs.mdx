## 当前实现

侧栏的 `logs` 入口挂载 `src/pages/Logs.tsx`；`request-log` 入口挂载 `src/pages/RequestLog.tsx`。这两个入口都在 `src/App.tsx` 的 `BASE_NAV` 中注册。

前端 wrapper 在 `src/services/api/proxy.ts`：代理日志使用 `proxy_log_list_filtered`、`proxy_log_get`、`proxy_log_settings_get`、`proxy_log_settings_set`、`proxy_log_cleanup_expired` 等命令；请求日志使用 `request_log_list`。

日志有三层开关：总开关、用户原始请求、上游请求。关闭某侧时，该侧 headers 和 body 不入库；Authorization 等敏感头在记录前脱敏。保留期清理按侧清空原始字段，整行保留期到期才删除。
