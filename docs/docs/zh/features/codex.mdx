# Codex

AiDog 可读取和编辑 Codex 配置，并为分组生成启动命令。Codex 经本机代理发送请求时，使用 AiDog 分组凭据；上游 API Key 保存在 AiDog 平台配置中。

在“系统设置 → Codex”管理 `~/.codex/config.toml`。分组页生成的命令会使用当前分组。若手动设置 provider，请确保 `base_url`、`wire_api` 和 `env_key` 与 AiDog 分组设置一致。

详细步骤见[接入 Codex](/zh/getting-started/connect-codex)和[Codex 推荐配置](/zh/features/recommended-codex)。
