# pi

AiDog 可为分组生成 pi provider，并管理 pi 全局设置。provider 配置写入 pi 的 `models.json`；AiDog 同步时只管理 `aidog-` 前缀条目。

分组列表提供 pi 启动命令。检查协议选择与模型后再启动。pi 与 Claude Code、Codex 支持的配置项不同；MCP、通知 Hooks 和 StatusLine 等能力不能按其他客户端的配置方式使用。

详细连接步骤见[接入 pi](/zh/getting-started/connect-pi)，其他设置见[pi 推荐配置](/zh/features/recommended-pi)。
