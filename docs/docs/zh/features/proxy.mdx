# 代理服务

桌面版会在本机启动代理。默认监听 `127.0.0.1:9890`，代理请求使用 `/proxy` 前缀，例如 `http://127.0.0.1:9890/proxy/v1/chat/completions`。

默认只监听本机回环地址。不要把代理管理接口转发到公网。若修改监听端口或启用局域网访问，请确认网络边界和访问控制设置。

可用 `GET /` 检查服务是否响应；成功时返回 `{"service":"aidog","ok":true}`。这只证明本机服务可连接，不证明上游凭证、模型或分组配置有效。
