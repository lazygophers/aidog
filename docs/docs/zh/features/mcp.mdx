## 当前实现

侧栏的 `mcp` 入口挂载 `src/pages/Mcp.tsx`。Tauri 命令在 `src-tauri/src/startup.rs` 中注册，前端 wrapper 走 `src/services/api/mcp.ts`。

当前文档站只应描述本仓库实际暴露的管理能力：列表、扫描、导入、更新、删除、重同步和分享导出。具体支持的字段与行为以 `src/services/api/mcp.ts` 与 Rust `ai_tools_cmd::mcp` 当前实现为准。

## 文档演示边界

演示数据是脱敏固定 fixture。它不代表真实 MCP 连接状态，也不连接任何本机或远端 server。
