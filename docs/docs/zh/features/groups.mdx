# 分组路由

分组位于“AI 平台”页。每个分组有独立凭据、模型映射和候选平台；客户端凭据决定请求进入哪个分组。

## 配置分组

1. 创建分组并保存分组凭据。
2. 把需要的上游平台加入分组。
3. 配置客户端模型到平台模型的映射。
4. 先用一个候选平台验证请求，再按需增加兼容平台和路由策略。

分组请求不会借用其他分组的平台。候选平台是否可用还取决于平台状态、模型槽位、协议、时段规则、额度和健康状态。详情请看[分组与路由原理](/core-concepts/groups-routing)。
