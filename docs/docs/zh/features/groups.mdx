## 当前实现

分组 UI 由 `src/pages/Groups.tsx` 及 `src/pages/Groups/` 组件实现，并嵌入到 `Platforms` 页。侧栏没有独立 `groups` 顶级入口；分组能力在 AI 平台页内使用。

前端 wrapper 在 `src/services/api/groups.ts`：`group_create`、`group_list`、`group_update`、`group_set_platforms`、`group_detail_list_paged`、`group_platform_move` 等命令通过 Tauri `invoke` 调用 Rust。统计 wrapper 有 `group_usage_stats` 和 `all_group_usage_stats`。

分组的 `group_key` 是本地代理鉴权 token。代理请求用 `Authorization: Bearer <group_key>` 或 Anthropic 风格 `x-api-key` 匹配分组；匹配失败不会跨分组借用平台。
