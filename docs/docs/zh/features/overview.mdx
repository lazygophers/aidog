## 当前实现

桌面侧栏的 `home` 入口挂载 `src/pages/Home.tsx`，入口定义在 `src/App.tsx` 的 `BASE_NAV`。首页不是 Local API 页面，也不是远程管理控制台。

首页可读取的数据必须来自 `src/services/api/` 中已有 Tauri wrapper 或前端本地状态。涉及代理、平台、统计、通知等模块时，具体命令以 `src-tauri/src/startup.rs` 的注册表和 `src/services/api/` wrapper 为准。
