# 客户端统计

客户端统计汇总本机 AI 编程客户端（Claude Code、Codex、Gemini CLI、OpenCode）本地会话记录里的用量：调用次数、Token 与折算花费。数据不经过代理，AiDog 只读取数字，不存对话原文。

隐私：读取默认关闭，每个客户端需在设置里单独同意后才开始；同意后 AiDog 只读这些会话文件并提取 token、模型、时间等元数据，不改写、不存储对话原文。

折算花费把读取到的 token 按对应官方平台条目价格折算，仅作参考、不替代上游账单；条目未定价时不折算（花费留空），不回落兜底单价。

保留天数单独设置（默认 90 天，可设为永久保留），到期清理只删数字，不影响客户端自己的会话文件。
