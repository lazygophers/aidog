# Claude Code

AiDog 可管理 Claude Code 设置、分组配置同步、Hooks 和 StatusLine。分组页提供启动命令，按命令启动可使用该分组对应的本机代理和凭据。

打开“系统设置 → Claude Code”管理全局配置；分组配置由 AiDog 写入独立文件。修改前确认当前用户目录和分组。AiDog 会记录其托管配置，用于后续同步和清理。

不要把上游 API Key 当作分组凭据。详细连接步骤见[接入 Claude Code](/zh/getting-started/connect-claude-code)，推荐设置见[Claude Code 推荐配置](/zh/features/recommended-claude-code)。
