## 当前实现

Claude Code 集成入口在设置页 `settings/claude` 和 AI 平台/分组的复制启动命令流程，不是要求用户手写 `export`。

`sync_group_settings` 和 `export_claude_config` 在 `src-tauri/src/startup.rs` 注册，Rust 实现会写 Claude Code settings，并把 aidog 托管路径记录到 DB。分组启动命令会带上当前代理地址和分组 token：`ANTHROPIC_BASE_URL` 指向本机 `/proxy`，`ANTHROPIC_AUTH_TOKEN` 使用分组名或分组 key。

StatusLine、Hooks 和默认联动开关属于当前源码内的 Claude Code 集成能力；具体字段以 `src-tauri/crates/aidog_core/src/sync_settings.rs`、`hooks` 模块和设置页源码为准。
