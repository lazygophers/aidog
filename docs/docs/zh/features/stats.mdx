## 当前实现

侧栏的 `stats` 入口挂载 `src/pages/Stats.tsx`。统计数据由 `src/services/api/stats.ts` 和后端 `platform_cmd::stats` 相关命令提供。

## 主要任务

此页面演示正常、空、错误和加载四种固定状态。演示数据已脱敏，不连接本机 aidog、Tauri IPC 或 Local API。

在桌面应用中使用左侧导航进入“统计”。保存会影响运行状态的设置前，先确认当前分组和平台范围；发生错误时结合[代理日志](/zh/features/logs)定位。
