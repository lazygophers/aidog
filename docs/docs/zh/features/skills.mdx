## 当前实现

侧栏的 `skills` 入口挂载 `src/pages/Skills.tsx`。技能相关能力来自 `src/services/api/skills.ts` 和 `src-tauri/src/startup.rs` 注册的技能命令。

当前页面支持的事实只有：浏览目录、搜索、已安装列表、刷新、启用、安装、详情、读取文件、禁用、更新、全部卸载、单个卸载、对齐 agents、全部启用。更细字段和平台差异以源码为准。
