# AI 平台

“AI 平台”保存 AiDog 转发请求所需的上游信息，包括协议、Base URL、API Key、模型槽位和平台状态。你可以使用内置预设，也可以添加自定义平台。

## 添加平台

1. 选择内置平台预设，或新建自定义平台。
2. 检查协议和 Base URL；Base URL 包含上游版本前缀，不包含具体请求路径。
3. 填入上游 API Key，并配置模型。
4. 保存后执行平台测试，确认凭证、地址和模型可用。

模型槽位可配置有序模型链。路由时先尝试链首模型，符合重试条件时再尝试后续模型。平台模型列表只是配置参考，不保证你的上游账号有该模型权限。

平台级“使用代理”开关控制该平台的出站请求是否使用 AiDog 配置的网络代理。代理地址为空或命中免代理名单时，请求仍会直连。
