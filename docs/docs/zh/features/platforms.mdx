## 当前实现

桌面侧栏的 `platforms` 入口挂载 `src/pages/Platforms.tsx`。该页由 `usePlatformsState` 编排，列表态使用 `PlatformListView`，新建和编辑态使用 `PlatformEditForm`。

平台 API wrapper 在 `src/services/api/platforms.ts`，覆盖平台创建、列表、更新、删除、分享解析、模型拉取、用量统计、余额和规则相关调用。Rust command 注册表在 `src-tauri/src/startup.rs`，`platform_create`、`platform_list`、`platform_update`、`platform_delete` 等命令必须在那里注册后才可被前端调用。

平台配置保存上游 Base URL、API Key、协议、模型、状态、extra JSON 和配额相关字段。`extra` 中当前有 mock、New API、Devin、breaker、peak、disable_during_peak、time_windows 等结构化子项，前端解析函数集中在 `src/services/api/platforms.ts`。
