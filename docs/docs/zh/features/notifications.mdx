## 当前实现

侧栏的 `notifications` 入口挂载 `src/pages/Notifications.tsx`，由 `src/App.tsx` 的 `BASE_NAV` 控制显隐。通知能力来自 `src/services/api/notification.ts` 和 Rust `system_cmd::notification` 注册命令。

应用还监听 `NOTIF_SPEAK` 事件做 Web Speech 播报；权限由桌面通知插件处理。编程助手 Hooks 的注入与移除也走同一命令集。

## 文档演示边界

上方演示是固定 fixture，只覆盖文档站的状态展示，不代表真实通知队列。

## 主要任务

此页面演示正常、空、错误和加载四种固定状态。演示数据已脱敏，不连接本机 aidog、Tauri IPC 或 Local API。

在桌面应用中使用左侧导航进入“通知中心”。保存会影响运行状态的设置前，先确认当前分组和平台范围；发生错误时结合[代理日志](/zh/features/logs)定位。
