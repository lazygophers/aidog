# pi

The group list provides a pi startup command. Check the protocol selection and models before launching. pi supports a different set of configuration options than Claude Code and Codex; capabilities such as MCP, notification hooks, and the statusline cannot be configured the way they are for other clients.

See [Connect pi](/en/getting-started/connect-pi) and [pi recommended settings](/en/features/recommended-pi).
