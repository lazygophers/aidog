# Claude Code

AiDog can manage Claude Code settings, group configuration sync, hooks, and the statusline. The group page provides a startup command; launching with it uses that group's local proxy and credentials.

Open **System Settings → Claude Code** to manage global configuration. Group configurations are written to separate files. Before editing, confirm the current user directory and group. AiDog records the configuration it manages so it can sync and clean up later.

Do not use an upstream API key as a group credential. For connection steps see [Connect Claude Code](/en/getting-started/connect-claude-code); for recommended settings see [Claude Code recommended settings](/en/features/recommended-claude-code).
