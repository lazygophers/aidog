# Home overview

The home page shows the local AiDog status and entry points for common features. Its content comes from current application data and does not represent remote service status.

If the proxy is not running, check the service status and listen address in the proxy settings. If request counts, costs, or balances differ from the upstream platform, check the request logs, price settings, and balance sources separately: they use different measures.
