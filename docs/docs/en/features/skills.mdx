# Skills

The Skills page lets you browse the catalog, search, install, enable, update, and uninstall Skills, and review installed content. Check the source and file contents before installing; Skill files can contain instructions that the client will execute.

Enablement can be managed per compatible client. pi scans the shared Skills directory, so it cannot switch individual Skills on and off the way Claude Code or Codex can.
