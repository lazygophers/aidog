# pi recommended settings

On the settings page `settings/pi`, click **Load recommended settings**. AiDog deep-merges the recommended values into the current configuration and, after confirmation, writes pi's global settings at `~/.pi/agent/settings.json` (change the root with `PI_CODING_AGENT_DIR`). Keys AiDog does not recognize are kept as-is and are not overwritten.

The source of truth is `PI_RECOMMENDED_CONFIG` in `src/services/pi-settings-schema.ts` — pi's official defaults plus AiDog's privacy preferences.

## Recommended values

| Key | Recommended value | Notes |
| --- | --- | --- |
| `defaultThinkingLevel` | `medium` | Default thinking level. Options: `off` / `minimal` / `low` / `medium` / `high` / `xhigh` / `max` |
| `defaultProjectTrust` | `ask` | Ask whether to trust a new project on first entry instead of trusting by default |
| `theme` | `dark` | UI theme |
| `quietStartup` | `false` | Keep startup info so you can confirm which provider is in use |
| `hideThinkingBlock` | `false` | Show thinking blocks |
| `enableInstallTelemetry` | `false` | Disable install telemetry |
| `enableAnalytics` | `false` | Disable usage analytics reporting |

The two telemetry switches match the Codex page's `analytics.enabled = false` and the Claude Code page's `DO_NOT_TRACK=1`.

## Keys AiDog owns — do not edit by hand

| Key | Who writes it |
| --- | --- |
| `defaultProvider` | Written by AiDog when a default group is marked; the value looks like `aidog-<group name>` |
| `httpProxy` | Written from AiDog's outbound proxy settings; it also applies to `HTTP_PROXY` and `HTTPS_PROXY` |

These two are not part of the recommended settings. If you edit them on pi's settings page, **the next group sync overwrites them with AiDog's values** — change them in AiDog's group and proxy settings instead.

The provider list itself is not in this settings file: it is generated by `src-tauri/crates/aidog_core/src/gateway/pi.rs` into `~/.pi/agent/models.json`, one `aidog-<group name>` provider per AiDog group, and syncs only clean up `aidog-`-prefixed entries. See [Connect pi](/en/getting-started/connect-pi).

## Other adjustable keys

The schema also covers these keys, which the recommended settings leave unset: `defaultModel`, `thinkingBudgets` (token budgets per thinking level), `externalEditor` (for example `code -w`), and `showCacheMissNotices`.

## Difference from the Claude Code page

The pi page's **Load recommended settings** is a direct deep merge with no per-item confirmation dialog. Also, MCP, notification hooks, statusline, and cc-switch import do not apply to pi, and Skills shows pi as always-on rather than a switch — see [pi integration](/en/features/pi).
