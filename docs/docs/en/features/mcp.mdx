# MCP

AiDog also offers an optional local MCP interface. The HTTP MCP endpoint is `POST /mcp`, authenticated with a group credential, and accepts local connections only. Tool calls are recorded in the tool log.

If a connection check fails, verify the service address, launch command, environment variables, and credentials. Do not share configurations that contain secrets.
