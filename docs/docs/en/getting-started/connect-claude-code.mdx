# Connect Claude Code

Open the group in AiDog's group list or **AI Platforms** page and choose **Copy startup command**, then select the Claude Code command.

The command generator lives in `src/domains/groups/commands.ts`. The command currently looks like:

```bash
claude --brief --dangerously-skip-permissions --settings ~/.aidog/settings.<group>.json
```

AiDog writes the group's Claude Code configuration into `settings.<group>.json` first; the command only points Claude Code at that settings file. The equivalent manual setup exists for reference, but do not hand-write `export` lines as the main flow:

```bash
export ANTHROPIC_BASE_URL="http://127.0.0.1:9890"
export ANTHROPIC_AUTH_TOKEN="<group_name>"
claude
```

`ANTHROPIC_AUTH_TOKEN` takes the aidog group name, not an upstream API key. You can also manage Claude Code configuration, hooks, statusline, and per-group sync under **System Settings → Claude Code**.

After running, verify the route in [Verify a request](/en/getting-started/first-request).
