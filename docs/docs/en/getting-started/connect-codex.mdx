# Connect Codex

1. Add and test an upstream provider in AiDog.
2. Create a group and add the provider to it.
3. Copy the Codex startup command from the group's actions.
4. Run the command and send one request.

AiDog syncs the Codex provider configuration. The group key is the credential Codex uses to reach AiDog, not an upstream API key. If you edit `~/.codex/config.toml` manually, keep the provider's `base_url`, `wire_api`, and environment variable names consistent with the group settings.

See [Codex recommended configuration](/en/features/recommended-codex) for the fields. Then check routing in [Verify a request](/en/getting-started/first-request).
