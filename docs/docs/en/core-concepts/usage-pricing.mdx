# Usage and cost estimates

Some models are priced per request, image, character, or time unit rather than only per token. When a model entry provides unit prices, cost resolution follows the matching pricing unit.

Group statistics aggregate requests by the group they belong to. Provider balances remain provider-level data. Balances, quotas, tokens, and estimated costs use different measures and should not be added together.
