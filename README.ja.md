# AiDog

**AIプラットフォームをローカルで管理し、クライアントのリクエストを選択したプラットフォームへ転送します。**

ローカルプロキシ、グループルーティング、モデルマッピング、リクエスト記録、使用量の推定を備えたデスクトップアプリです。

[ドキュメント](https://lazygophers.github.io/aidog/en/) · [最新リリース](https://github.com/lazygophers/aidog/releases/latest) · [問題を報告](https://github.com/lazygophers/aidog/issues)

AiDogは、お使いのコンピューター上でプロキシサービスを実行します。上流プラットフォームとAPIキーをAiDogに保存し、Claude Code、Codex、piなどの互換クライアントをローカルプロキシに接続します。リクエストは引き続き選択した上流サービスへ送信されます。ローカルで動作しても、リクエストがコンピューター内に留まるわけではありません。

## 対象ユーザー

- 複数のAIサービスを利用し、プラットフォームの認証情報とモデルを1つのアプリで管理したい方。
- クライアントごとに異なるグループ、モデルマッピング、候補プラットフォームを使いたい方。
- リクエストの状態、使用量、推定コスト、ルーティング結果を確認したい方。
- Claude Code、Codex、piで1つのローカルプロキシ入口を共有したい方。

### ローカルプロキシとルーティング

- 内蔵プラットフォームのプリセットを管理し、カスタムプラットフォームも設定できます。
- グループでクライアントのリクエストを分離し、各グループに個別のプラットフォームを関連付けます。
- モデルマッピング、エンドポイントのプロトコル、利用可能状態に基づいて候補プラットフォームを選択します。
- 複数モデルのスロットでは順序付きモデルチェーンを設定できます。リクエストに失敗すると、後続の候補を試します。
- OpenAI、Anthropic、Geminiなどのプロトコル転送と適応に対応します。実際の機能はプラットフォームのエンドポイントとリクエスト種別によって異なります。
- ミドルウェアルール、時間帯別モデル設定、ルーティングのヘルススケジューリングに対応します。

### ログと統計

- プロキシリクエストに加え、テスト、残高照会、モデル一覧取得の記録を個別に確認できます。
- 設定に応じてリクエストの両側の生データを保持または消去します。機密性の高いリクエストヘッダーはマスキングされます。
- 応答の使用量と内蔵モデル価格からコストを推定します。推定値は上流サービスの請求額に代わるものではありません。
- プラットフォーム残高、クォータ、グループ別使用統計を確認できます。これらは集計方法が異なるため、直接比較できません。

### クライアントとツール

- Claude Code、Codex、piの設定を管理し、グループごとの接続方法を生成します。
- MCPサーバー、Skills、通知、システム設定を管理します。
- 必要に応じてヘッドレスカーネルを実行し、ローカルアクセスに制限された管理APIから操作できます。

## インストール

[GitHub Releases](https://github.com/lazygophers/aidog/releases/latest)から、お使いのシステムに合ったインストーラーをダウンロードしてください。各リリースページに、システムごとのパッケージ、アーキテクチャ、要件が記載されています。

AiDogの起動後、ローカルプロキシは既定で`127.0.0.1:9890`をリッスンします。既定ではループバックアドレスのみを使用します。管理APIを公開インターネットへ転送しないでください。

## クイックスタート

1. 「AIプラットフォーム」でプラットフォームを追加し、プロトコル、Base URL、上流APIキーを入力します。
2. プラットフォームページでグループを作成し、プラットフォームを追加します。
3. クライアントでそのグループ用に生成された接続コマンドを使うか、クライアント接続ガイドに従ってローカルプロキシのアドレスとグループ認証情報を設定します。
4. リクエストを送信し、プロキシログでグループ、上流プラットフォーム、モデル、結果を確認します。

[インストールガイド](/en/getting-started/installation) · [初期設定](/en/getting-started/first-config) · [最初のリクエストを確認](/en/getting-started/first-request)

## データとプライバシー

AiDogは設定とデータベースをローカルに保存します。プロキシリクエストは必要な内容を選択した上流サービスへ転送します。リクエストログにリクエスト本文と応答本文を保存するかどうかはログ設定によります。生データの記録を無効にしても、状態、モデル、使用量などのメタデータは記録される場合があります。[データとプライバシー](/en/core-concepts/data-privacy)を参照してください。

## ソースから実行

[公式Tauri前提条件](https://v2.tauri.app/start/prerequisites/)に従って、必要なツールとシステム依存関係を先にインストールしてください。

```bash
git clone https://github.com/lazygophers/aidog.git
cd aidog
yarn install
yarn tauri dev
```

インストーラーをビルドするには：

```bash
yarn tauri build
```
