# 代理端口固定不漂移 + 占用即失败提醒 — 详细设计

架构 / 数据流 / 关键取舍 / 技术选型 (不含调度图, 调度归 task.json):

## 根因

两处叠加，缺一不成 bug：

1. **绑定层自动换端口** —— 代理绑定失败且原因是「地址已被占用」时，把端口 +1 重试，最多试 100 次。设计意图是「尽量让它跑起来」，代价是跑在了一个用户不知道的端口上。
2. **启动成功后把实际端口回写设置** —— 这才是「每次重启都变成别的」的真正机制。第 1 点只让**本次**跑在别的端口上；第 2 点把这个偏移**固化进配置**，于是下次启动以新端口为起点，再撞再加，**单向漂移、永不回归**。

单看第 1 点像个善意兜底；正是第 2 点让它变成不可逆的配置污染。**两处都要改**，只改一处：
- 只改 1 不改 2：端口不漂了，但回写逻辑还在，是颗留给后人的雷。
- 只改 2 不改 1：设置里还是 9890，实际却跑在 9891，**症状更隐蔽**（用户看设置以为对，请求却打空）。

## 取舍

| 方案 | 评价 |
|---|---|
| 保留自动换端口，只是不回写设置 | **否决** —— 用户明确要「提醒被占用启动失败而不是换一个端口」。且设置与实际不一致比直接失败更难排查 |
| 占用即失败，不回写设置 | **采纳** —— 与用户诉求逐字对应；失败是响亮的，隐性偏移是安静的，响亮的失败更便宜 |
| 加个「是否允许自动换端口」开关 | **否决** —— 用户没要；一个只有一种合理取值的开关是纯负担（YAGNI） |
| 启动时检测端口在漂移区间就重置回默认 | **否决** —— 用户已拍板不做迁移；无法区分「被漂坏的 9891」与「用户故意设的 9891」 |

## 方案

**绑定层**：地址被占用时直接返回错误，不再递增重试。错误需**保留端口号**并让上层能判别「这是端口占用」而非其他绑定失败（权限、地址非法等）——上层要据此选不同文案。其他绑定失败照旧原样返回，不与占用混为一谈。

**启动命令层**：删掉「保存实际使用的端口到设置」这一步。端口是**用户的输入**，不是程序的输出，启动流程无权改写它。其余收尾动作（分组 settings 文件同步、托盘刷新）保持不变，只是所用端口从「实际端口」变为「用户设定端口」——两者现在恒等，但语义上应显式取用户设定值。

**提醒层**，按触发路径分两条通道：

- **手动启动**（有前端窗口）：错误经 command 返回值回到前端 → 主窗口内**持久错误条**（非 toast），含端口号与重试入口。重试 = 再调一次启动，不需重启应用。
- **自启动**（无前端窗口）：当前只 `tracing::error!`。补两条用户可见通道 —— **系统通知**（复用项目已有的通知能力，勿新造）+ **托盘菜单**能看出未启动（复用既有的托盘刷新事件，勿新造刷新链路）。

两条通道的**文案同源**：一句「端口 N 被占用，代理未启动」，在 8 语言 locale 里各一份。禁在 Rust 侧硬编码中文再传给前端显示。

## 边界情况

- **占用的是别的程序 vs 上一次自己没退干净**：不区分，都是「端口被占用」。区分需要枚举占用进程，收益不抵复杂度。
- **绑定 `0.0.0.0` 与 `127.0.0.1`**：占用判定一致，不因绑定模式分叉。
- **重试时端口已被释放**：正常启动成功，错误条消失。
- **重试时端口仍被占**：错误条保持，不堆叠出第二条。

## 测试接缝 (seam)

check 阶段验证的是`行为对不对`而非`跑没跑起来`, 全靠这里选对接缝。三条规则:
1. 优先复用现有接缝, 不新建
2. 取最高接缝 (越靠外部行为越好)
3. 越少越好, 理想 = 1 个

- **接缝 = 代理启动函数的返回值 + 启动后的设置值**（Rust 侧 `#[test]`）。一个接缝同时覆盖本 task 的两条根因：
  - 先占住一个端口 → 调启动 → 断言返回 Err **且**该错误可判别为端口占用（不断言文案全文，文案会变）
  - 启动前后读设置里的端口值 → 断言**未被改写**（这条专钉根因 2，没有它 bug 会回来）

  复用 `gateway/proxy/` 下既有 `#[test]` 的起服务写法（`test_integration.rs` / `test_connect.rs` 已有 bind 端口起 axum 的先例），**不新建测试基建**。
- **前端提醒不开自动化接缝** —— 错误条 / 系统通知 / 托盘跨 Tauri 边界与系统 API，自动化成本远高于收益，改由 check 阶段人工确认一次。i18n 复用既有 `scripts/check-i18n.mjs` 静态扫描，不另开接缝。
